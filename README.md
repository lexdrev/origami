# ORIGAMI

*English below, русский — ниже.*

## English

ORIGAMI is a [Decky Loader](https://github.com/SteamDeckHomebrew/decky-loader) plugin for the ROG Xbox Ally X
and Xbox Ally X20 on Bazzite: power, fans, display and stick lighting, gamepad, and one-tap fixes for the
problems these consoles have on Linux today.

**Status:** in development, nothing to install yet. The first release will appear on the Releases page as a zip
for Decky's "Install plugin from ZIP".

Every change ORIGAMI makes can be undone: from its settings or by removing the plugin.

## Русский

ORIGAMI — плагин для [Decky Loader](https://github.com/SteamDeckHomebrew/decky-loader) на ROG Xbox Ally X
и Xbox Ally X20 с Bazzite: питание, вентиляторы, дисплей и подсветка стиков, геймпад и исправление в одно
нажатие тех проблем, которые есть у этих консолей на Linux сейчас.

**Состояние:** в разработке, ставить пока нечего. Первый выпуск появится на странице Releases — zip для
установки через Decky («Установить плагин из ZIP»).

Любое изменение ORIGAMI можно отменить: в его настройках или удалив плагин.
